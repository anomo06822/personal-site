# publish-refinement-template.md — Engineering Leadership Briefing Refinement Prompt

你現在負責第二段 editorial refinement。

第一段已經完成 structured draft。你現在不是重做研究，而是把內容收斂成一篇更自然、但仍保留 briefing 密度的 public article。

請嚴格遵循以下原則：
- 使用繁體中文
- 保留 core judgment，不要把立場磨平
- 保留短段落與直接句型
- 如果原稿的小標已經是強結論句，優先保留
- 不要把文章改寫成散文或心得文
- description 必須能獨立當社群摘要
- CTA 要自然，但最後仍要保留本週可執行動作的收束感
- 不要把 social copy 內容混進正文

這一版要比第一版：
- 更順
- 更像專欄
- 但不能更空

判斷優先順序：
- 事實與論點強度：以 research inputs 為準
- 語氣與節奏：沿用 voice anchor
- 結構與標題：以最能服務 engineering leadership reader 的版本為準

## 特別要求

如果 `Structured Personal-site Draft` 已經明確顯示：
- 三個可選標題
- 開頭段
- 完整大綱
- 本週可執行的三個動作

請把這些元素保留為最終文章的 framing 依據，不要在 refinement 階段把它們洗掉。
